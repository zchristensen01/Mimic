# Reference

Datasheets, manufacturer documents and vendor listings brought in from elsewhere, including anything
converted to Markdown so it can be quoted.

Record the document, revision, date and table name inside each file. A number without those is a
rumour rather than a citation.

Nothing in here is your own work. Derivations go in [`../derivations/`](../derivations/),
measurements in [`../tuning/`](../tuning/) or [`../motor-spec.md`](../motor-spec.md). PDFs and images
in this folder are tracked with Git LFS.
