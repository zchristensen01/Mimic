# Derivations

Photographed pages of your own handwritten algebra, committed the day you did them.

A photograph or scan of a page you worked out by hand. Phone camera is fine: legible beats
beautiful. Each workbook's **Draw this** sections are the full list of pages the project expects.

Not here: diagrams produced in software, copies of a figure from the guides, or final write-ups.

## Naming

```
YYYY-MM-DD-<what-it-is>.jpg
```

The date is what makes the page evidence, and it is the only part of the filename that cannot be
reconstructed later.

## Storage

Images here are tracked with Git LFS, see [`.gitattributes`](../../.gitattributes). Run
`git lfs install` once on each machine you clone to, or the tracking rules silently do nothing.
