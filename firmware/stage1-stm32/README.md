# Stage 1: The Smart Joint

**Empty until Stage 1.** This directory holds the STM32CubeIDE project: the Stage 0 controller
running as a FreeRTOS task on a Nucleo-F446RE, as an independent node on a CAN bus.

Ten sessions, S1.0 to S1.9, in [the Stage 1 Workbook](../../docs/guides/Mimic_Stage1_Workbook.md).
Do not start it until every criterion in the Stage 0 exit gate is true.

A separate project rather than another PlatformIO environment because CubeMX owns the generated code
and the `.ioc` is the source of truth for peripheral configuration.

## What goes in here

| | |
|---|---|
| The CubeIDE project | Generated by STM32CubeMX, hand-edited only inside the `USER CODE` fences |
| `.ioc` | Committed. It is the peripheral configuration, and it is exempted from `.gitignore` on purpose |
| Application code | The Stage 0 classes, ported |

Regeneration eats anything outside the `USER CODE` fences. S1.0 has you prove that deliberately,
once, on purpose.
